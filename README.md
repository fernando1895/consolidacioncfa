# Consolidación CFA – Sistema de Asistencia

Aplicación web para el **Ministerio de Consolidación & Ministración – Dpto. de Consolidación y Célula**.

## Descripción

Sistema de registro y seguimiento de asistencia que permite gestionar:

- Fecha del evento
- Participación en el devocional
- Propósito de convocatoria (Consolidar / Ministrar / Ambos)
- Color de equipo asignado
- Turno del culto (AM / PM)
- Nombre y apellido del asistente
- Líder de Célula
- Línea a la que pertenece

## Tecnologías

- **Backend:** PHP 8.0+
- **Base de datos:** MySQL / MariaDB
- **Frontend:** HTML5 + CSS3 (diseño responsivo)

## Instalación

Consultar el archivo **[INSTALL.md](INSTALL.md)** para instrucciones detalladas de instalación en Windows, Linux y macOS.

## Inicio rápido

1. Copiar los archivos al directorio del servidor web.
2. Importar `database.sql` en MySQL.
3. Configurar `config/database.php` con las credenciales de su base de datos.
4. Abrir `index.php` en el navegador.
